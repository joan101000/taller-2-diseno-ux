## Descripción del proyecto

Este proyecto consiste en el desarrollo de un formulario web que permite identificar y describir fallas en los computadores de los laboratorios universitarios.

El formulario fue diseñado aplicando principios de experiencia de usuario (UX), buscando que sea sencillo, claro y fácil de utilizar.

## Funcionalidades

- Campos obligatorios identificados con asteriscos rojos.
- Instrucciones para completar cada campo.
- Selección del laboratorio y del equipo.
- Registro de fecha y hora de la falla.
- Selección del tipo de problema.
- Campo adicional que aparece al seleccionar «Otro problema».
- Validación de la información ingresada.
- Mensajes de confirmación y error.
- Confirmación antes de limpiar el formulario.

## Tecnologías utilizadas

- **HTML:** estructura del formulario.
- **CSS:** diseño y presentación visual.
- **JavaScript:** validaciones e interactividad.

## Principios UX aplicados

- **Usabilidad:** facilidad para completar el formulario.
- **Utilidad:** recopilación de información relevante sobre las fallas.
- **Deseabilidad:** interfaz visual organizada, clara y agradable.
